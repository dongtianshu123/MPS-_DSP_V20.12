## 详细修改

### P0-1: 启用看门狗 WDT

**位置：** `src/MainCont.c:105`

**问题：** 原 `_FWDT(WDT_OFF)` 禁用看门狗，但主循环却有 `asm("CLRWDT")`。程序跑飞后无法自动复位。

**修改：**
```c
// 修改前
_FWDT(WDT_OFF);

// 修改后
_FWDT(WDT_EN & WDT_POST_1024 & WDT_PRE_256);
```

**看门狗超时：** ~284ms（主循环10ms周期，28倍余量）

### P0-2: EEPROM写入IPL保护修复

**位置：** `src/RelayFlow.c:520~531, 536~547` + `src/Uart2.c:254~268, 270~284, 286~301, 303~318`

**问题：** 写完EEPROM后 `SET_CPU_IPL(3)` 硬编码恢复，忽略进入时的原始IPL值。如果函数被高优先级中断调用（IPL=5/6），会将IPL错误降低到3。

> ⚠️ **注意：** `SET_CPU_IPL` 宏（`p30f5011.h:3731`）**已内建** `DISI #0x3FFF` 保护，所以中断打断问题不存在。真正的问题只有IPL硬编码恢复。

**修改前（代表）：**
```c
SET_CPU_IPL(7);     // IPL提升到7（含DISI保护）
// ... EEPROM操作 ...
SET_CPU_IPL(3);     // ❌ 硬编码恢复，丢失原始IPL
```

**修改后：**
```c
unsigned int savedIPL;
SET_AND_SAVE_CPU_IPL(savedIPL, 7);  // 保存原始IPL并提升到7
// ... EEPROM操作 ...
RESTORE_CPU_IPL(savedIPL);          // ✅ 恢复到进入前的原始IPL
```

**涉及函数（共6个）：**
| 文件 | 函数 | 行号 |
|:----|:-----|:----:|
| RelayFlow.c | `EEWrFaultLastTime()` | 520-531 |
| RelayFlow.c | `EEWrLastStartTime()` | 536-547 |
| Uart2.c | `EEWriteApp()` | 254-268 |
| Uart2.c | `EEWriteApp2()` | 270-284 |
| Uart2.c | `EEWriteApp3()` | 286-301 |
| Uart2.c | `EEWriteApp4()` | 303-318 |
