###  MPS 软起动器 Modbus 寄存器映射文档

#### 基本通讯参数

- **通讯协议**：Modbus-RTU (从站)
- **波特率**：由 `StartParams.modbusbaud` 设定 (常用 9600/19200)
- **数据格式**：8-N-1 (1位起始位, 8位数据位, 1位停止位)
- **功能码支持**：03H (读保持寄存器), 06H/10H (写寄存器)

**通讯规范：**

- **功能码**：03 (读), 06/16 (写)
- **数据格式**：16位无符号整型 (Unsigned Word)

#### 遥控与遥调寄存器 (写/读)

| **偏移地址(Hex)** | **Modbus 地址** | **变量名称** | **操作码/范围** | **功能描述**                    |
| ----------------- | --------------- | ------------ | --------------- | ------------------------------- |
| **0064H**         | **(40101)**     | 遥控起动指令 | **0x00AA**      | 写入 0xAA 触发电机软起动        |
| **0065H**         | **(40102)**     | 遥控停止指令 | **0x00BB**      | 写入 0xBB 触发电机软停/紧急停止 |
| **0066H**         | **(40103)**     | 遥控复位指令 | **0x00CC**      | 写入 0xCC 清除系统当前故障锁定  |
| **0067H**         | **(40104)**     | 远程遥调数据 | **0~65535**     |                                 |



### 三、 附表：按位(Bit)定义说明

#### 附表 1：输入点状态 (40007)

| **Bit** | **定义**    | **物理含义 (1为有效)** |
| ------- | ----------- | ---------------------- |
| Bit 0   | INPUT_START | 外部起动信号           |
| Bit 1   | INPUT_STOP  | 外部停止信号           |
| Bit 2   | INPUT_READY | 外部就绪允许           |
| Bit 15  | FWD_REV     | 正反转切换 (1:反转)    |

#### 附表 2：输出点状态 (40008)

| **Bit** | **定义**     | **物理含义 (1为有效)** |
| ------- | ------------ | ---------------------- |
| Bit 0   | OUTPUT_READY | 备妥继电器输出         |
| Bit 1   | OUTPUT_START | 起动继电器输出         |
| Bit 5   | OUTPUT_ALARM | 报警继电器输出         |
| Bit 7   | OUTPUT_K6    | 故障跳闸继电器输出     |

#### 附表 3：系统状态位 (40017)

| **Bit** | **定义** | **说明**   |
| ------- | -------- | ---------- |
| Bit 0   | 相位比对 | 1:正常     |
| Bit 1   | 远程就绪 | 1:允许起动 |
| Bit 3   | 温度保护 | 1:温度正常 |
